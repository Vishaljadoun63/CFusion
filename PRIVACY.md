# CFusion Privacy Policy

**Last updated: November 12, 2026**

## 1. Introduction

CFusion is a browser extension that enhances the Codeforces problem-solving experience by providing an integrated coding workspace, Monaco Editor, custom test cases, and code execution functionality.

This Privacy Policy explains how CFusion processes and handles information when you use the extension.

## 2. Information Processed

CFusion may process the following information to provide its features:

- **Source code:** Code written or pasted into the CFusion editor.
- **Custom input:** Input data provided by users for testing their code.
- **Workspace preferences:** Theme settings and editor preferences.
- **Saved solutions:** Code snippets that users explicitly save in their local code library.
- **Codeforces page information:** Problem titles, identifiers, and sample test cases needed to provide the coding workspace.

## 3. Local Storage

CFusion uses the browser's local storage API to save workspace preferences, editor drafts, custom test cases, and solutions saved by users.

This information is stored locally in the user's browser and is not automatically synchronized to a CFusion cloud account.

## 4. Code Execution and Third-Party Services

When a user explicitly clicks the Run button, the relevant source code and input data are transmitted over HTTPS to the CFusion execution backend.

The backend forwards the submission to Judge0, a third-party code execution service, to compile and execute the program. The execution result is then returned to CFusion.

Code and input data are processed for the purpose of providing the requested execution service. Users should avoid submitting passwords, API keys, personal information, or other sensitive data in their code or input.

The processing and retention of submissions by third-party execution services are subject to their respective policies.

## 5. Data Sharing

CFusion does not sell users' personal information.

Source code and input data are shared with the execution service only when users request code execution. This sharing is necessary to provide the execution functionality.

## 6. Data Security

CFusion uses HTTPS when communicating with its hosted execution backend. Users are encouraged not to include confidential credentials or sensitive personal information in submitted code or input.

No internet-based service can guarantee absolute security.

## 7. Children's Privacy

CFusion is a general-purpose educational and programming tool. It is not designed to collect personal information from children.

## 8. Changes to This Policy

This Privacy Policy may be updated when CFusion's features or data-handling practices change. Updated versions will be published in the project's GitHub repository.
